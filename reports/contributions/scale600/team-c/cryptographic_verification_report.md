# Cryptographic verification: Batches 01–14

The one hundred forty baseline suites exercise ECDSA P-256 signatures; reference suites exercise ML-DSA-65 signatures using cryptography 50.0.2. Tests cover valid claims, wrong signing keys, altered persisted payloads, record identifier binding, public key serialization, malformed PQC public keys, domain validation, scoped verification and deactivation. Lexical post-migration scan results are stored per application. Tests and scans are evidence of tested behavior only, not formal security proofs or certification.
