# CaseExchange

Controlled synthetic legal document exchange application for OPMB-600. Matter-scoped document exchange, recipient access, and signed custody events. Classical baseline: RSA-3072 OAEP/PSS. Migration target: ML-KEM-768 + ML-DSA-65. Candidate specifications only; no reference migration or test outcome is claimed.

Run `python -m pytest` after installing the pinned requirements.
