# DevicePair

Controlled synthetic iot device enrollment application for OPMB-600. Manufacturing-time device enrollment, ownership transfer, and signed configuration delivery. Classical baseline: RSA-3072 OAEP/PSS. Migration target: ML-KEM-768 + ML-DSA-65. Candidate specifications only; no reference migration or test outcome is claimed.

Run `python -m pytest` after installing the pinned requirements.
